探究1：盐水动力小车与电离本质

观察神奇的“盐水小车”：只需加入 NaCl 固体和水，小车就能跑起来！

NaCl 固体
离子受限，不能自由移动
→
NaCl 溶液
解离出自由移动的离子

阿伦尼乌斯观点： 电解质溶于水即电离，不需要通电。

探究2：电离方程式书写

师：电离是微观过程，我们用化学符号来表征。请尝试书写以下物质的电离方程式：

题目：书写 硫酸 (H₂SO₄) 的电离方程式

书写规则总结：
  • 原子守恒、电荷守恒
  • 原子团（如 SO₄²⁻）一般不拆
  • 强电解质用“=”，弱电解质用可逆号

探究3：从电离角度认识酸、碱、盐

请观察以下电离产物，归纳它们的共同点：

物质电离方程式归纳定义
HCl, H₂SO₄... = H⁺ + ...阳离子全部是 H⁺ 的是 酸
NaOH, KOH... = ... + OH⁻阴离子全部是 OH⁻ 的是 碱
NaCl, KNO₃... = Mⁿ⁺ + Rⁿ⁻产生金属/铵根离子和酸根离子的是 盐

电解质 → (溶于水/熔融) → 自由移动离子 → 导电能力
